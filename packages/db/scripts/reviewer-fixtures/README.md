The founder approved these three bundled Toyota Camry Hybrid XLE XV70 Graphite Metallic photographs on 2026-10-07 for issue #714. Both fixed reviewer Listings use this demo vehicle. The photographs show the vehicle, while the Listings and their seller/disclosure scenarios are fictional.

These resized derivatives remain under CC BY-SA 4.0.

Runtime reviewer seeding reads these files locally. It never downloads from Wikimedia or any other external source. Seeding and revocation remain operator actions; bundling the fixtures does not run a live seed.
