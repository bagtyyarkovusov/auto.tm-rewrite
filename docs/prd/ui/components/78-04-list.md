# 78-04 — List

## Purpose

Vertical (or horizontal) sequence of items. Covers: long scrollable lists, grouped settings, tappable rows.

## When to use

- Settings rows (`Profile / Notifications / Theme / About`)
- Members of a dealership
- Conversation thread list
- Favorites list (1-column on mobile, grid on tablet)
- Chat message list (specialized — see Conversations CONTEXT)

## When NOT to use

- 2D collections of equal items — use a Grid layout
- Forms — use form layout
- Selection of one — use Radio group

## Variants

### Layout

| Variant | Use |
|---|---|
| `flat` | Plain stacked items, no separators |
| `divided` | 1px divider between items |
| `cards` | Each item is a Card |
| `inset-divider` | Divider with left padding matching content (Material-style) |

### Density

| Token | Row height |
|---|---|
| `compact` | 48 |
| `comfortable` (default) | 56 |
| `spacious` | 72 |

## Anatomy

Each row contains:
- Leading: optional icon, avatar, image
- Content: title + optional subtitle
- Trailing: optional icon (chevron, action button), badge, switch

```
┌─────────────────────────────────────────┐
│ [icon]  Title                  [chevron]│
│         Subtitle (optional)             │
└─────────────────────────────────────────┘
```

## Components

- `<List>` — container
- `<ListItem>` — single row; tappable if `onPress`/`onClick` provided
- `<ListSeparator>` — dividers between items (auto-inserted with `divided` variant)
- `<ListSection>` — labeled section (sticky header optional)
- `<ListEmpty>` — empty state component (see [75-illustration-style.md](../75-illustration-style.md))

## Long list performance

- Mobile: use `FlatList` (virtualized rendering); set `keyExtractor`, `getItemLayout` for known sizes
- Web: use windowing library if > 100 items (react-window or built-in `<Virtualizer>`)
- Avoid mounting all items at once for unbounded lists

## Pull-to-refresh + infinite scroll

- Mobile: standard `RefreshControl` + `onEndReached` for pagination
- Web: scroll listener + intersection observer
- Cursor-based pagination (see [33-search-discovery.md](../../features/33-search-discovery.md))

## Accessibility

- `accessibilityRole="list"` on container, `accessibilityRole="listitem"` on items
- Each item announces title + subtitle + trailing state
- Disabled items: `accessibilityState={{ disabled: true }}`

## Implementation (web)

```tsx
<List variant="divided" density="comfortable">
  <ListItem
    leading={<Avatar src={user.avatarUrl} />}
    title={user.name}
    subtitle={`${user.role} · ${user.tenure}`}
    trailing={<ChevronRight />}
    onClick={() => router.push(`/users/${user.id}`)}
  />
  <ListItem ... />
</List>
```

## Implementation (mobile)

```tsx
<FlatList
  data={users}
  keyExtractor={u => u.id}
  ItemSeparatorComponent={ListSeparator}
  renderItem={({ item }) => (
    <ListItem
      leading={<Avatar uri={item.avatarUrl} />}
      title={item.name}
      onPress={() => router.push(`/users/${item.id}`)}
    />
  )}
  refreshControl={<RefreshControl refreshing={refreshing} onRefresh={onRefresh} />}
  onEndReached={loadMore}
/>
```

## Don'ts

- ❌ Custom row designs that drift from `ListItem` — extend, don't fork
- ❌ Multi-column lists — use a Grid component
- ❌ Inline complex content (forms, multiple actions) — split into separate screens
- ❌ Auto-loading more on scroll without a "load more" affordance for unbounded lists
