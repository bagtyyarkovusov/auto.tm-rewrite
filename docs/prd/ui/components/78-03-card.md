# 78-03 — Card

## Purpose

Bounded surface containing related content. The most-used container component.

## When to use

- Listing in the feed (`ListingCard`)
- Dealer in a dealer list (`DealerCard`)
- Conversation in the chat list (`ConversationCard`)
- Settings group on the settings screen
- Stat cards on the admin dashboard
- Blog post in the blog feed

## When NOT to use

- Single isolated text — use plain text + spacing
- Forms — use form layout primitives + Input
- Pages themselves — pages aren't cards

## Variants

### Elevation

| Variant | Visual |
|---|---|
| `flat` (default) | No shadow, no border — just bg color |
| `bordered` | 1px border `neutral-200` |
| `elevated` | `shadow.sm`; subtle lift on hover (web) |
| `interactive` | `bordered` + cursor pointer + hover bg shift |

### Padding

| Token | Padding | Use |
|---|---|---|
| `none` | 0 | Custom layout |
| `sm` | 12 | Compact cards |
| `md` (default) | 16 | Most cards |
| `lg` | 24 | Stat cards, dashboards |

## Anatomy

```
┌──────────────────────────────────┐
│ Header  (optional)               │
│ ────────                         │
│ Body                             │
│ - Image / content                │
│ - Text                           │
│ ────────                         │
│ Footer  (optional)               │
└──────────────────────────────────┘
```

Composition:
- `<Card>` — outer container
- `<CardHeader>` — optional title row
- `<CardBody>` — main content
- `<CardFooter>` — optional actions / metadata row

Most cards are composed by the consumer, not all-in-one.

## ListingCard (specific instance — used everywhere)

The most important card in the app. Used in: feed, favorites, my-listings, related listings, dealer showroom, saved-search match preview.

### Layout

```
┌────────────────────────────────┐
│                                │
│  [ Cover photo, 16:10 ratio ]  │
│                                │
│                                │
│  Badge (top-left, optional)    │
│  Favorite ♥ (top-right)        │
├────────────────────────────────┤
│ Price • TMT                    │
│ Brand Model · Year             │
│ Mileage · Region               │
└────────────────────────────────┘
```

### Properties

- Cover photo: `list` variant (600×400), `aspectRatio: 16/10`, `objectFit: cover`
- Top-left badge: "Новый" / "Справедливая цена" / "Trusted by AutoTM" (Phase 2)
- Top-right Favorite ♥: tappable, filled when favorited
- Price: bold, `lg` size; currency in `textSecondary`
- Specs: `sm` size, `textSecondary`

### Variants

- `feed-card` — in a column grid; tap opens listing detail
- `horizontal-strip` — in "Related listings" carousel
- `mini-card` — in chat post-card refs; smaller (photo + price + model only)

## ConversationCard (chat list)

```
┌─────────────────────────────────────────┐
│ [Avatar]  Seller Name      14:32        │
│           Brand Model · Year            │
│           Last message preview…   (3)   │
└─────────────────────────────────────────┘
```

- Tap → open thread
- Unread count badge in bottom-right
- Bold if unread; regular if read
- Muted icon if conversation is muted

## Accessibility

- Whole card is one focusable interactive element if `interactive` variant
- Inner Favorite button is a separate focusable element (stop event propagation on tap)
- Screen reader reads: "Toyota Camry 2019, 189000 manat, 47000 kilometers, Aşgabat. Tap to view."

## Implementation (web)

```tsx
<Card variant="interactive" padding="none" onClick={() => router.push(`/listings/${id}`)}>
  <CardBody>
    <Image src={photoUrl} alt="" className="aspect-[16/10] object-cover" />
    <div className="p-4">
      <h3 className="font-bold text-lg">{price} {currency}</h3>
      <p className="text-secondary text-sm">{brand} {model} · {year}</p>
      <p className="text-secondary text-sm">{mileage} km · {region}</p>
    </div>
  </CardBody>
</Card>
```

## Don'ts

- ❌ Nested cards (cards inside cards) — flatten the hierarchy
- ❌ Cards with > 5 actions / buttons — split into multiple cards or a list
- ❌ Heavy shadows — keep `shadow.sm` for elevated; never `shadow.lg` for cards
