Use the workflow already in place

Coordination that pays for itself

  • One release map and one integration owner per issue. Check live reservations before dispatch.
  • Save every pushed checkpoint, exact-SHA review and evidence result as it completes. A final chat message is insufficient recovery state.
  • Serialize overlapping Cabinet and edit writes. Admit native/build work using the actual host profile.
  • Keep the human-only domain, migrations, push/device, signing and Console work in explicit founder blocks.

What to leave for later

  • No further general workflow rewrite while the current release queue runs.
  • #404/#407/#452 remain excluded under the founder scope decision, even though the audit discusses their value.
  • Support Conversations, dealer/general chat, trust reserve and future marketplace bets follow the reviewer release.
  • Measure a small set of comparable PRs and founder waits before changing model, review or concurrency defaults.

Repository policy and host permissions still apply. Cloud does not inherit the Mac's simulator, private archives, local proof files or provider logins. The handoff includes the required capability check and recovery route.
