## Judgment

Raw model capacity is available across several subscriptions; the bottleneck is deciding scope, recovering work, and validating integrated user behavior. Treat unused capacity as recovery/review reserve. Use one integration coordinator and a proposed starting point of two disjoint writers, while retaining current host-specific profiles and independent final reviews. Do not invent a new permanent concurrency rule or silently change the founder's explicit review-model preference.

Report recommendations should be bounded. Freeze release outcomes, establish durable prototype/PR evidence, repair freshly reproduced cross-boundary bugs, clear known CI faults, and measure8-12PRs before changing process again. Current launch-grade security or trust failures override the process experiment and deserve immediate scoped repairs.
