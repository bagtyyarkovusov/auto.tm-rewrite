# Content

This area reserves the boundary for blog publishing. The `BlogPost` schema exists, but the feature's application behavior is not implemented. There is no registered API module or public route for this deferred capability.

Keep schema/migration history and account-purge consumers intact. Do not infer a shipped user flow or event pipeline from a model or port proposal. Future scope belongs to the roadmap and owning product requirement, not a list of promised implementation details here.
